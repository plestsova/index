# 🧮 Калькулятор дробей

Веб-приложение для решения примеров с обыкновенными, неправильными и смешанными дробями.

## Возможности

- Поддержка всех видов дробей:
  - правильные (3/4)
  - неправильные (7/3)
  - смешанные (2 1/4)
  - целые числа (6/3 = 2)
- Операции: +, −, ×, ÷
- Автоматическое сокращение
- Пошаговое объяснение решения
- Показ результата в 3 видах: обыкновенная, смешанная, десятичная
